## 검증과 교훈

이번에는 AST 39개와 합성 정규화 3개만 검사했다. 원본 HTML·실제 DB 상태와 쇼핑몰 결과는 측정하지 않았다. 페이지 단위 문자열 검색은 의도와 다른 영역을 포함할 수 있고, 규격이 다른 상품을 합치면 가격 비교 자체가 무의미해진다. 요청 간격·파일 형식은 과거 문서가 아닌 현재 파일과 대조해야 한다.

관련 파일: `src/main.py`, `src/crawlers/compuzone/ram_crawler.py`, `src/normalizers`, `requirements.txt`, 기존 FINAL·REFACTOR 문서. 수정 문서의 성공 표현을 이번 실행 성공으로 바꾸지 않았다.
