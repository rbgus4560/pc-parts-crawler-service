# 개발 과정

전체 기간 2주·개인 프로젝트는 사용자 확인 사항이다. 아래 단계의 정확한 발생일은 미상이며 기존 수정 문서와 코드에서 재구성했다.

1. 사이트별 목록·상세 수집과 부품별 모델을 구성.
2. 상품/규격/판매처/가격 이력 및 수집 로그 저장 역할을 분리.
3. 사이트→부품 폴더로 재구성하고 공통 요청 코드를 BaseCrawler로 분리.
4. FINAL 기록: 컴퓨존 페이지네이션, 다나와 전용 카테고리·상품카드 fallback, 규격별 식별키와 가격 없음 건너뜀.
5. V2: RAM 총 용량 표기·상세/판매처 재시도, 누락 후 건너뜀 보완.
6. V3: 데스크톱 RAM 제한·모듈 수 표기 확장. V4: 페이지 전체 제외 검사로 모든 RAM이 제외되는 문제를 상품명·규격 범위로 좁힘.
7. V5: RAM 속도가 5600→600 등으로 잘못 추출되는 표기 처리 보완. 컴퓨존 RAM만 재수집 전 정리하는 SQL 추가.
8. 2026-10-22: 문서·구성도 작성. 현재 간격/requirements 차이 확인 및 구문·합성 입력 검사. 사이트·DB 재실행은 하지 않음.

원본 문서는 `docs/history/README.md`에서 연결한다. 데이터 행 수·수집 성공률·기간별 성과는 확인되지 않아 추정하지 않았다.


2026-10-23 소스 공개 준비: 실행 코드·정적 자산·패키지 선언과 빈 설정 예시만 선별했다. 비밀 환경 파일·의료 OCR 원본·로그·가상환경·node_modules·dist는 제외한다. 기존 문서 기록은 보존하며 크롤러 requirements 줄바꿈 수정·버전 고정, 실행 스크립트 경로 이식성과 Python 인자 지원, 병원 백엔드 requirements 추가 및 ignore 보완을 수행했다. 설치·외부 API·실사이트·운영 DB는 실행하지 않았다.
