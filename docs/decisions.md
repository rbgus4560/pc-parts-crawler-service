# 구조와 설계의 근거

확인한 코드를 기준으로 현재 역할을 설명하며 선택 당시 개인 의도를 추측하지 않는다.

- 사이트별·부품별 크롤러: HTML 변화와 규격 파싱의 영향을 분리한다. 근거 `REFACTOR_NOTES.md` 및 `src/crawlers`.
- 공통 BaseCrawler와 Repository: 요청/대기와 DB 저장을 재사용하고 파서의 책임을 줄인다.
- RAM·SSD 식별키: 이름뿐 아니라 용량·규격 차이가 가격 비교의 단위가 되도록 한다. 모든 상품의 완전 매칭 알고리즘은 아니다.
- 가격 이력과 현재 판매 정보 분리: 상품 상세·판매처 비교·날짜별 가격 조회에 사용한다.
- 기본 호환성: 소켓·메모리 타입 조건만 명시하고 전체 조립 가능 판정으로 표현하지 않는다.
- 문서화: 기존 V2~V5 실패·수정 기록을 보존하고 현재 값과 차이를 명시한다. 코드·설정·DB·사이트를 임의로 변경하지 않는다.
